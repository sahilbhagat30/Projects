# HR Dashboard Project

## Overview
The HR Dashboard project is designed to provide HR managers with actionable insights into employee data using Tableau. This dashboard visualizes key HR metrics such as employee demographics, hiring trends, and income analysis, enabling better decision-making and workforce management.

---

## Features

### 1. Overview
- **Employee Status**: Displays the total number of hired, active, and terminated employees.
- **Hiring and Termination Trends**: Visualizes the number of hires and terminations over the years.
- **Department and Job Title Breakdown**: Presents employee distribution across departments and job titles.
- **Location Comparison**: Compares employee counts between headquarters (New York) and branches, and shows distribution by city and state.

### 2. Demographics
- **Gender Ratio**: Illustrates the gender distribution within the company.
- **Age and Education Distribution**: Visualizes employee counts across different age groups and education levels.
- **Education and Performance Correlation**: Examines the relationship between educational backgrounds and performance ratings.

### 3. Income Analysis
- **Salary Comparison by Education and Gender**: Analyzes salary differences across education levels and between genders.
- **Age and Salary Correlation by Department**: Investigates how age correlates with salary within each department.

### 4. Employee Records View
- Provides a detailed list of all employees, including information such as name, department, position, gender, age, education, and salary.
- Allows users to filter the list based on any of these attributes for in-depth analysis.

---

## Dataset
The dataset used in this project consists of 8,950 simulated employee records, generated using ChatGPT prompts and the Python Faker library. It includes:
- **Demographics**: Gender, age, education, etc.
- **Job Details**: Department, position, hire/termination dates.
- **Salary Information**: Salary distribution across various groups.
- **Performance Evaluations**: Performance ratings and their correlation with other attributes.
- **Attrition Data**: Data on terminated employees.

The dataset is included in the `data` folder of this repository.

## How to Recreate the Dashboard

### Prerequisites:
- Install Tableau Public (free software).
- Download the project materials (dataset, icons, images, etc.) from the repository.

### Steps:
1. Import the dataset into Tableau.
2. Follow the step-by-step guide provided in the project video tutorial:
   - [YouTube Tutorial](https://www.youtube.com/watch?v=UcGF09Awm4Y)
3. Use the provided icons and images to enhance the visual appeal of the dashboard.
4. Publish your final dashboard to Tableau Public.
